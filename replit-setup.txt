REPLIT SETUP INSTRUCTIONS:

1. Open https://replit.com
2. Click "+ Create Repl"
3. Choose "React" template
4. Name: "apurp-task-app"
5. Click "Create Repl"

6. Replace package.json with:
{
  "name": "apurp-task-app",
  "version": "0.1.0",
  "dependencies": {
    "react": "^18.2.0",
    "react-dom": "^18.2.0",
    "react-router-dom": "^6.8.0",
    "@supabase/supabase-js": "^2.51.1",
    "react-scripts": "5.0.1"
  },
  "scripts": {
    "start": "react-scripts start",
    "build": "react-scripts build",
    "test": "react-scripts test",
    "eject": "react-scripts eject"
  }
}

7. Create .env file with:
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

8. Replace src/App.jsx with the provided code
9. Replace src/main.jsx with the provided code
10. Create all other files (contexts, components, lib)

11. Click "Run" button - you'll get instant live URL!

The URL will be like: https://apurp-task-app.yourusername.repl.co
